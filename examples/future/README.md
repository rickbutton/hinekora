# Crafts that wait on a feature

Each file here is a real recipe written the way players give it, and each fails the
checker today for the reason its first comment names (a deferred item of
`docs/ROADMAP.md` or `docs/operations.md` §3.2). They are not tested; when the feature
lands, the file moves up to `examples/` and joins the suite the tests run. A file whose
syntax is proposed rather than built (`lock … keep`) is a design sketch, not a commitment.
